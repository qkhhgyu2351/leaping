00核心结论
盈利拐点出现在 Q2：Q2 归母净利同比 +29.66%，扭转 H1 整体 −20.54% 的颓势——全年成色就看这个势头能否延续到 Q3、Q4。
DPO ≈149 天，账期即护城河：应付账款+应付票据合计 2297.69亿，超出 144 天（60×2.4）行业超阈值标尺约 5 天；现金循环周期 ≈0 天——用供应商的钱养存货和应收。
海外首超国内：海外收入 1812.68亿，占比 52.57%；海外销量 79.2万辆（+67.8%）——全球化从故事变成了报表事实。
70.96% 负债率看着吓人，其实多为无息经营性负债：应付类合计 ≈3356.91亿、占总负债 50.26%；短期借款 376.46亿 被现金储备充分覆盖。
三个待核点决定结论下限：现金口径差（≈1674亿 vs 587.38亿）、海外分区域毛利、研发资本化节奏——见第 07 节。
01公司概况与商业模式

一句话：全球新能源整车 + 动力电池垂直一体化的制造商，靠"自供 + 规模 + 技术平台"压成本，靠出海与高端化找第二增长曲线。

业务与品牌：乘用车（王朝 / 海洋 / 腾势 / 方程豹 / 仰望）+ 商用车；电池、电机、电控、半导体高度自供（弗迪系）；关联上市平台比亚迪电子（0285.HK）承接电子代工分部。

2026H1 的关键事实：海外收入占比 52.57% 首超国内；巴西 / 欧盟以本地化建厂对冲关税；智驾能力受 GB7258 安全强标影响推进节奏（见风险）。

三条翻译（把数字翻译成生意语言）

1. 149 > 144：对上游的占款强度已越过"60×2.4"行业超阈值标尺——规模越大、议价越强，账期即护城河。

2. "60 天"≠ 合并口径：该承诺仅适用中小企业供应商，报表读数要认 149 天——对外叙事与合并报表是两套语言。

3. CCC≈0 是效率也是依赖：存货+应收全靠供应商垫资，扩张几乎不占自有现金；一旦供应商信用收缩，首当其冲（见 06-5）。

口径与方法：DPO =（应付账款 + 应付票据）÷ 营业成本 × 181 天；DSO ≈26 天、DIO ≈123 天为同口径自算；营业成本为毛利率反推的推算值。图表配色遵循涨红 / 跌绿。

流动性测试

0.87 的流动比率放在传统制造业是警报，但在"负债一半是应付类"的结构里，它衡量的是供应链信用的滚动能力，不是偿付能力。

真正的偿付测试是短期借款 376.46亿：即便按最窄现金口径 587.38亿 也覆盖 1.56×；按宽口径现金储备 ≈1674亿 则覆盖 ≈4.4×（口径差待核，见 07-1）。

06治理与风险（六项）
关税与地缘高

巴西 35% 关税、欧盟反补贴税直接压制出海利润率；对冲靠本地化建厂，但投产前是利润逆风。

国内价格战高

H1 减收减利（−7.13% / −20.54%），Q2 拐点（+29.66%）能否延续是全年最大的不确定性。

汇率波动中

海外收入占比已 >50%，汇兑损益对利润表的扰动被同步放大。

GB7258 智驾强标中

智驾功能的安全强标抬高合规门槛，影响功能上车节奏与相关成本。

账期依赖中

CCC≈0 建立在 DPO 149 天之上；供应商信用若收缩（政策或竞争驱动），现金与扩张同步承压。

研发资本化口径低

费用化研发 −21.25%，若资本化比例同步变化，利润的可比性受口径影响，需回附注核对。

07待核事项（下钻清单）
现金口径差：宽口径"现金储备"约 1674 亿 vs 窄口径 587.38 亿——两个数都来自公开检索但口径未闭合，需回半年报附注确认构成（是否含定期存款 / 理财）后，才能用于流动性结论。
海外分区域毛利：拉美 / 欧洲 / 东南亚各自的毛利水平决定"海外故事"的成色——52.57% 是量，分区域毛利率才是质。
研发资本化节奏：费用化研发 −21.25% 与资本化比例的变化需对照附注，剔除口径影响后再谈研发强度。
比亚迪电子（0285.HK）分部：分部收入 / 利润及并表影响需单独拆出，避免与整车主业毛利混读。
08结论

比亚迪 2026H1 是"规模收缩期的质量切换"：收入与利润双降，但 Q2 拐头、经营现金流为正且改善；现金循环周期 ≈0 天、DPO ≈149 天的供应链资金效率，既是它最深的护城河，也是最集中的风险源；海外收入占比 52.57% 首超国内，把估值叙事从"国内价格战"切换到"全球化 + 关税落地能力"。
